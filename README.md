# 🎬 Movie Industry Data Analysis

## 📌 Overview

This project analyzes movie industry data to identify key factors influencing profitability. The analysis includes budget, revenue, genre, ratings, awards, and studio performance.

## 📊 Objectives

* Identify most profitable movies
* Analyze genre performance
* Determine best release timing
* Evaluate impact of actors, directors, and awards
* Study studio-level performance

## 🛠️ Tech Stack

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn

## 🔍 Key Features

* Data cleaning and preprocessing
* Feature engineering (Profit, ROI)
* Multi-dataset merging
* Exploratory Data Analysis (EDA)
* Data visualization

## 📈 Visualizations

* Budget vs Revenue scatter plot
* Genre-wise profit bar chart
* Monthly performance analysis
* Correlation heatmap

## 💡 Key Insights

* High-budget movies generate higher revenue but not always higher profit
* Genre selection plays a critical role in profitability
* Release timing significantly impacts performance
* Awards and ratings influence success more than runtime

## 🚀 Conclusion

This project demonstrates how data-driven insights can guide strategic decisions in the movie industry.
